# job-application-analysis(Interactive Dashboard Creation using ms Excel)

## 📌 Project Objective
A data analytics dashboard designed to track recruitment metrics, application trends, and hiring pipeline performance through interactive Excel visualizations.

## 🛠️Tools
 - Microsoft Excel
 - Data Modeling (Star Schema)
 - Data Visualization
 - Slicers

## Questions(KPIs)
- How many job applications have been submitted overall?
- Which application status has the highest frequency?
- What is the interview conversion rate from total applications?
- Which companies receive the highest number of applications?
- Which job roles or locations show the most opportunities?
- How effectively is the recruitment pipeline performing?
- What percentage of applications result in offers or interview calls?
- Which stage of the application process has the highest drop-off rate?

  ## 📊 Data Architecture & Pipeline

The project utilizes a snapshot execution model across four distinct states to track data changes across time:
* **Start Applied / Start Pending:** Initial pipeline state capturing baseline application records, salary brackets, and target timelines.
* **End Applied / End Pending:** The concluding timeline state used to measure final funnel outcomes, rejections, and offer conversions.

## Process

- Imported the cleaned dataset into Excel for analysis and reporting.
-  Analyzed recruitment and application data using pivot tables and KPI-based metrics.
- Designed interactive dashboards to visualize application trends, interview progress, and hiring outcomes.
- Applied data visualization techniques to generate actionable insights and improve recruitment tracking efficiency.
