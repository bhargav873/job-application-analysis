# job-application-analysis(Interactive Dashboard Creation using ms Excel)
A data analytics dashboard designed to track recruitment metrics, application trends, and hiring pipeline performance through interactive Excel visualizations.

## Questions(KPIs)
- How many job applications have been submitted overall?
- Which application status has the highest frequency?
- What is the interview conversion rate from total applications?
- Which companies receive the highest number of applications?
- Which job roles or locations show the most opportunities?
- How effectively is the recruitment pipeline performing?
- What percentage of applications result in offers or interview calls?
- Which stage of the application process has the highest drop-off rate?

## Process

1. Imported the cleaned dataset into Excel for analysis and reporting.
2. Analyzed recruitment and application data using pivot tables and KPI-based metrics.
3. Designed interactive dashboards to visualize application trends, interview progress, and hiring outcomes.
4. Applied data visualization techniques to generate actionable insights and improve recruitment tracking efficiency.
